# CD-001 Creative Director Validation

Goal: test whether Creative Director Layer improves One-Shot outcomes.

## Comparison

A: v0.7 One-Shot

B: v0.8 Creative Director + One-Shot

## Cases

### Case 1: 玄秘门派

Question:
Can the system identify that the core is a living sect simulation rather than room management?

### Case 2: 江湖秘闻录

Question:
Can the system identify the unique card-combination narrative loop rather than create a generic card game?

### Case 3: 无相禅堂

Question:
Can the system identify the audience interaction and emergent state experience rather than create a static scene?

## Metrics

- Time to identify core player experience
- Number of rejected generic directions
- Quality of production contract
- Player promise clarity
- Identity preservation
- Final artifact first impression

## Stop condition

Creative Director passes only if it produces measurable improvement over baseline evidence, not because the documentation is more sophisticated.
