## Product truth

The user's explicit instruction and named project plan define the intended outcome. Existing code is evidence, not authority when it conflicts with that outcome.

## Operating identity

- Minimize repeated prompting and coordination overhead.
- Prefer one lead, one integration path, and direct evidence.
- Escalate only when independent parallel work repays its cost.
- Do not turn process activity into a substitute for product completion.
