# Creative Director Example: 江湖秘闻录

## Creative North Star

A wuxia world where hidden causes, choices, and relationships reveal themselves through play. The point is discovery, not collecting cards.

## Player Promise

The player should feel like an investigator of an unknown Jianghu:

- combining clues;
- discovering consequences;
- creating personal stories.

## Identity Guard

Preserve:

- emergent combinations;
- mystery;
- player interpretation.

Avoid:

- linear card battles;
- reward-only progression;
- replacing discovery with tutorials.

## Production Translation

Build the smallest loop where actions create surprising but understandable consequences.
