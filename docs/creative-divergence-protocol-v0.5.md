# LoopSeed Creative Divergence Protocol v0.5

## Purpose

Extend LoopSeed for invention tasks without turning creativity into another optimization loop.

The protocol protects two independent properties:

- **Novelty integrity:** the artifact must retain the reason it is different.
- **Execution quality:** the artifact must withstand evidence-based comparison.

## Phase 0 — Divergence Gate (runs once)

Run only when the value of the task depends on being unlike existing work.

### Concept generation

Generate multiple candidate concepts. A novelty adversary rejects:

- concepts summarized as `<existing thing> but <twist>`;
- concepts that are merely safe, competent, or decorative.

For surviving concepts define:

- one-line core loop;
- three non-negotiable commitments.

## Ablation validation

For each commitment, construct a version without it.

If the artifact still works without the commitment, it is decoration, not structure.
Reject the concept.

A concept can only be frozen when its unusual properties are load-bearing.

## Freeze invariant

Write `CONCEPT.md` and freeze it.

The concept's unusual properties are protected. Quality critics may attack execution, but may not classify protected commitments as defects.

## Bar acquisition

Do not invent a quality bar.

Collect real external artifacts with provenance. Prefer cross-domain craft references when direct similarity would cause cloning.

The bar may become harder, never softer.

## Phase 1 — Convergence Loop

Use the normal LoopSeed evidence loop.

Required additions:

- independent critics inspect real running artifacts;
- blind comparison when applicable;
- critic must identify the largest remaining tell;
- protected concept commitments never count as tells;
- winners are frozen against regression.

## Drift detection

Periodically rerun ablation.

If removing a protected commitment no longer damages the artifact, the loop has routed around the concept. Treat this as novelty drift and repair before other improvements.

## Human gate

After Phase 0, optionally pause once for human approval of:

- frozen concept;
- ablation evidence;
- collected bar.

No other human continuation is required.
