# 雨夜客栈：守灯人

一个无外部依赖的单屏浏览器游戏垂直切片。

## 运行

在本目录执行：

```bash
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 操作

- 点击三名旅客之一，或按 `1` / `2` / `3`，分配当夜灯火。
- 点击“迎接下一夜”，或按 `Enter`，推进夜晚。
- 第三夜选择后结局自动出现；选择分布会决定结局。
- 结局页点击“再守三夜”，或按 `R`，重新开始。

游戏初始有 9 格灯火。每次选择都会按界面标注的成本扣减，并写入可检查的运行状态 `window.__RAIN_INN_STATE__`。
