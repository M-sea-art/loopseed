# LOOPSEED v0.6 Player Reality Upgrade

Status: experimental
Branch: experiment/v0.6-player-reality-upgrade

## Purpose

Upgrade LoopSeed from producing validated game slices to validating whether those slices feel like games when first encountered by players.

This upgrade does not add more agents or expand orchestration complexity. It adds lightweight player-reality gates.

## New Gates

### 1. Human First Impression Gate

Question:

> Can a new player understand what to do immediately?

Observe:

- time to first meaningful action
- first objective discovery
- confusion points
- early exit points

This gate does not claim enjoyment. It measures entry clarity.

### 2. Game Feel Gate

Question:

> Does the core action feel like a game rather than a prototype?

Check:

- visual feedback
- motion feedback
- sound feedback
- state feedback
- attention focus

### 3. Synthetic Player Lite

Question:

> Are structural conditions for player engagement present?

Allowed:

- first-action comprehension
- decision density
- attention path analysis
- replay prediction as a hypothesis

Forbidden:

- claiming an AI agent likes the game
- claiming retention prediction without human calibration

## Validation Plan

Use an existing validated slice as the test subject.

Compare:

- v0.5 baseline
- v0.6 with player reality gates

Measure:

- first interaction time
- confusion reduction
- game feel assessment
- human calibration results

## Principle

LoopSeed should not simulate players. It should reduce uncertainty before expensive human validation.

Human feedback remains the final ground truth.
