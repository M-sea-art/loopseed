# Creative Director Template v0.1

## Creative North Star

### Why does this work exist?

Describe the irreplaceable reason this project should exist.

### Desired player feeling

Describe the emotional state after the first session.

### Unique identity

What makes this project impossible to replace with a generic version?

---

## Player Promise

### Core fantasy

What role does the player inhabit?

### Core loop

What repeated action creates enjoyment?

### Hero moment

What moment makes the player think: "I want to continue"?

---

## Identity Guard

### Must preserve

Elements that cannot be sacrificed for faster implementation.

### Forbidden substitutions

Examples:
- static scene instead of game
- dashboard instead of player experience
- generic assets instead of project identity

---

## Production Translation

Convert the creative decision into:
- vertical slice boundary
- required systems
- evidence gates
- verification method
