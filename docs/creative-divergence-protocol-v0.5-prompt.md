# Creative Divergence Execution Prompt

```
GOAL: <artifact>

If success depends on being unlike existing work, run DIVERGENCE GATE once.
If success depends on matching an existing target, skip it and use that target as BAR.

DIVERGENCE GATE:
Generate unusual candidates. Kill anything that is merely an existing thing plus a twist.
For each survivor define one core loop and three non-negotiable commitments.
Run ablation: remove each commitment. If the artifact survives, reject it.
Freeze CONCEPT.md. Protected commitments are never execution defects.

BAR:
Source real external artifacts. Never imagine a bar.
Store provenance. Audit whether the bar is too weak. Bars only ratchet upward.

CONVERGENCE LOOP:
Use subagents. Choose the implementation approach.
First create an observation harness so an independent critic can experience the real artifact.

Split into independently judgeable pieces. Attack the weakest first.

Builders explore different routes. Fresh critics inspect only the real artifact.
When applicable, run randomized blind A/B: first guess which is ours, then identify the biggest tell.
Protected concept commitments are never tells.

Freeze winners. Never regress.
Periodically rerun ablation to detect novelty drift.

Keep live evidence: CONCEPT.md, BAR provenance, ablation status, progress, captures.

Never soften the concept. Never lower the bar. Never claim completion without evidence.
```
