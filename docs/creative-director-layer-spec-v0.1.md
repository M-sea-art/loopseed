# LoopSeed Creative Director Layer v0.1

## Purpose

Creative Director Layer is a decision layer above production execution.
It does not replace builders, add more agents, or create competing interpretations.
Its purpose is to preserve the strongest player experience before implementation begins.

## Principle

More agents do not create better games.
Better creative judgment creates better production direction.

LoopSeed should remain:

Seed → Understanding → Production → Evidence

not:

Seed → Agent swarm → Feature accumulation

## Position in Pipeline

```
User Seed
    ↓
Creative Director Layer
    ↓
Creative North Star Lock
    ↓
Production Contract
    ↓
One-Shot Production
    ↓
Controlled Fan-out
    ↓
Player Reality Verification
    ↓
Evidence Verdict
```

## Responsibilities

### 1. Creative North Star

Answer:

"Why should this experience exist?"

Required output:

- core fantasy
- emotional promise
- player motivation
- unique identity

### 2. Player Promise

Answer:

"What should the player feel and do repeatedly?"

Required output:

- first minute experience
- core loop
- memorable moment
- retention reason

### 3. Identity Guard

Answer:

"What must never be sacrificed for implementation convenience?"

Examples:

- atmosphere
- character relationships
- unusual mechanics
- visual identity

## Anti-Goals

Creative Director Layer must not:

- become another autonomous agent swarm
- create unnecessary documents
- increase user configuration burden
- replace evidence verification
- approve unfinished artifacts

## Evaluation Experiment

Validate with three projects:

1. Wuxia sect management game
2. Jianghu Mystery Record card narrative game
3. Wuxiang Zen Hall interactive game

Compare against v0.7 baseline:

Metrics:

- player clarity
- creative uniqueness
- first impression quality
- production deviation rate
- evidence confidence

## Success Condition

Creative Director Layer succeeds only if the same natural-language seed produces a noticeably stronger creative direction without increasing user effort.
